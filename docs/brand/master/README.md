asset, UI, and brand generation. The binding status and usage rules are in
`../../strategy/CORPORATE_POSTURE_AND_BRAND.md`.

This directory intentionally contains no reconstructed artwork. Do not trace the concept-board raster,

working master.

When the owner supplies or approves the exact production asset, store it here with:

- the source vector or other owner-approved master file;
- any approved raster exports needed for ordinary use; and
- a short provenance note identifying the source, approval date, approved variants, and any usage limits.

Adding or refining that artwork requires explicit owner authorization. Until then, use the concept board
as a visual reference only when it is supplied in the active task, and use a clearly labelled placeholder
when logo geometry would otherwise need to be invented.
