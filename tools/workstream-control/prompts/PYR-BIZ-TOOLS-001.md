## Task: Business Operations Tool Stack

Identify the third-party software and services worth adopting to run Pyrnova across sales, finance, support, documentation, security, analytics, communications, automation and operations — while actively avoiding SaaS sprawl.

Do this:

1. **Function map.** List the operational functions a near-launch company genuinely needs now vs later. Mark which are needed at Phase 1 and which can wait.

2. **Recommendations per function.** Using current web research, recommend a primary pick (and one alternative) for each needed function, with: what it does, rough cost at Pyrnova's scale, why it fits, and any lock-in or security concern. Favour tools that consolidate multiple needs and that a solo/small team can actually operate.

3. **Anti-sprawl discipline.** Explicitly flag overlaps and where one tool should cover several jobs. Recommend a deliberate *stop list* — categories to defer and tempting tools to skip for now.

4. **Security & data posture.** Given Pyrnova's sensitivity, note tools that need extra scrutiny (data residency, access, integrations) and any that should be avoided.

5. **Standup plan.** Give a short, sequenced adoption plan: what to set up first, rough monthly cost of the Phase 1 stack, and what triggers adding the next tier.

Deliver a lean, opinionated stack with a running cost estimate — not a catalogue. Cite pricing and capability facts with dates.
